# 📊 Dashboard de Análise de Vendas e Receitas

## 📌 Sobre o projeto

Este projeto consiste em um dashboard interativo para análise de vendas e receitas, desenvolvido com o objetivo de transformar dados comerciais em informações visuais que facilitem o acompanhamento do desempenho da empresa.

O dashboard permite analisar a receita mensal, comparar meta x receita, acompanhar o desempenho dos vendedores e visualizar a distribuição das vendas por diferentes produtos e ferramentas.

## 🎯 Objetivo

O principal objetivo do projeto é facilitar a interpretação dos dados de vendas e auxiliar na identificação de:

- Evolução da receita ao longo do ano;
- Comparação entre meta e receita realizada;
- Desempenho individual dos vendedores;
- Receita gerada por produto;
- Produtos com maior e menor participação nas vendas;
- Comparação do desempenho entre diferentes anos.

## 📊 Principais análises

### Meta vs Receita

Visualização mensal comparando a meta estabelecida com a receita obtida, permitindo identificar períodos de maior ou menor desempenho.

### Receita por Produto

Análise da receita gerada por cada produto ao longo dos meses, possibilitando identificar tendências e produtos de maior representatividade nas vendas.

### Análise por Vendedor

Comparação do desempenho dos vendedores, permitindo visualizar quais profissionais apresentaram os maiores resultados no período analisado.

### Vendedor vs Produto

Cruzamento entre vendedores e produtos para identificar a contribuição de cada vendedor na receita de diferentes produtos.

## 💡 Desenvolvimento

O projeto foi construído a partir da organização e análise dos dados de vendas, utilizando recursos de tratamento, consolidação e visualização de informações.

Após o tratamento dos dados, foram desenvolvidos indicadores e gráficos para apresentar as informações de forma mais clara, objetiva e visual, permitindo uma análise rápida dos principais resultados.

## 📈 Resultados

O dashboard proporciona uma visão consolidada do desempenho comercial, permitindo analisar diferentes perspectivas dos dados em um único ambiente.

Com isso, torna-se mais fácil acompanhar indicadores, comparar períodos, identificar oportunidades e apoiar processos de tomada de decisão baseada em dados.
